# Product Overview

This is a personal portfolio website for Matin Jahi, a frontend developer specializing in Vue.js and Nuxt.js.

## Key Features

- Modern, animated portfolio showcasing development expertise
- Interactive UI with custom cursor, particle effects, and 3D elements
- SEO-optimized with structured data and meta tags
- Dark/light mode support
- Smooth page transitions and scroll animations
- Responsive design with mobile-first approach

## Target Audience

Potential employers, clients, and collaborators looking to view the developer's work and expertise in modern web technologies.

## Deployment

The site is deployed on Netlify at https://matinjahi.netlify.app
